1) FULL SETUP (root)
   sudo bash scripts/setup.sh
   cd /opt/ryzenc2
   source venv/bin/activate
   python3 app.py

2) USER INSTALL (không root)
   ./scripts/install.sh
   source venv/bin/activate
   python3 app.py

3) ĐĂNG NHẬP CLI
   User: admin
   Pass: ryzenc2_secure_2026

4) BẬT API
   Trong menu chọn 11
   Port mặc định: 8080
   Header: X-API-Key: ryzenc2_api_key_change_me

5) GIAO DIỆN WEB
   cd frontend && python3 -m http.server 3000
   Mở http://127.0.0.1:3000

6) PROXY SCRAPE
   Menu 3 → 5  hoặc
   curl -X POST -H "X-API-Key: ryzenc2_api_key_change_me" \
     http://127.0.0.1:8080/api/v1/proxies/scrape

7) TUNNEL
   scripts/ryzenc2-tunnel.sh

8) DOCKER
   docker compose up --build

Chỉ dùng hệ thống được ủy quyền / lab.
